# Changelog

## [3.6.1] - 2026-11-18
### Added
- Blur support for Instagram DM quoted reply bubbles, `"You replied to ..."` labels, active `"Replying to ..."` composer previews, and the full-screen media viewer.

### Changed
- Kept the Instagram DM message input box in its default appearance without dimming/opacity effects.

## [3.6.0] - 2026-11-18
### Added
- Support for **Instagram DM** (`instagram.com/direct/*`), automatically blurring chat list names, profile pictures, message previews, chat bubbles, media, and text input until hovered.
- Individual platform toggles (**WhatsApp** and **Instagram DM**) in the popup so you can enable or disable blur per app.

### Changed
- Renamed the extension to **Privacy Chat Auto Blur** to reflect multi-platform support.
- Unified blur, idle timer, and schedule settings globally across supported chat apps while preserving your existing WhatsApp preferences.
